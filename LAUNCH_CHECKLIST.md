# SnapSum Launch Checklist

## Pre-Launch
- [ ] Generate proper 128x128, 48x48, 16x16 PNG icons (replace placeholders)
- [ ] Take 3+ screenshots of the extension in action (1280x800 px)
- [ ] Create a promotional tile (440x280 px)
- [ ] Test on a clean Chrome profile (no cached data)
- [ ] Test with no API key — should show clear error message
- [ ] Test with invalid API key — should show clear error
- [ ] Test summarize on 5+ different page types (news, blog, docs, Wikipedia)
- [ ] Test right-click "Summarize Selection"
- [ ] Test keyboard shortcuts Ctrl+Shift+S and Ctrl+Shift+C
- [ ] Test dark mode toggle
- [ ] Test export buttons (copy at minimum)
- [ ] Test history save/load
- [ ] Test Read Later add/remove
- [ ] Test persona switching
- [ ] Test language translation
- [ ] Test chat suggestions
- [ ] Verify no console errors
- [ ] Verify no permissions warnings beyond what's needed

## Store Listings
- [ ] Extension name: "SnapSum — AI Page Summarizer"
- [ ] Short description (132 chars): "Summarize any webpage in one click with AI. Interactive chat, source citations, translation, and exports to Notion/Obsidian."
- [ ] Detailed description written
- [ ] Category: Productivity
- [ ] Screenshots uploaded
- [ ] Icons uploaded
- [ ] Privacy practices declared

## Chrome Web Store
- [ ] Register at chrome.google.com/webstore/devconsole ($5 one-time)
- [ ] Upload ZIP
- [ ] Fill listing
- [ ] Submit for review
- [ ] Wait 1-3 business days

## Microsoft Edge Add-ons
- [ ] Register at partner.microsoft.com/dashboard/microsoft-edge/submit ($19 one-time)
- [ ] Upload same ZIP
- [ ] Fill listing
- [ ] Submit for review
- [ ] Wait 1-3 business days

## Firefox Add-ons (optional, Phase 2)
- [ ] Register at addons.mozilla.org (free)
- [ ] Add popup fallback for Firefox (no sidePanel support)
- [ ] Upload ZIP
- [ ] Submit for review
- [ ] Wait 1-2 days

## Post-Launch
- [ ] Monitor reviews and ratings
- [ ] Respond to user feedback
- [ ] Fix any reported bugs within 48 hours
- [ ] Plan v1.1 features based on feedback
- [ ] Share on Product Hunt, Reddit r/extensions, Twitter
- [ ] Add to Awesome Chrome Extensions list
