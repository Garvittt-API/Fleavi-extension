## Chrome Web Store

### Step 1: Pay $5 fee
Go to https://chrome.google.com/webstore/devconsole
Sign in with Google → pay one-time $5 registration fee

### Step 2: Click "New Item" → upload fleavi-v1.0.0.zip

### Step 3: Fill in listing (copy-paste below)

**Name:** Fleavi — AI Page Summarizer

**Summary (132 chars max):**
Summarize any webpage in one click with AI. Interactive chat, source citations, translation, and exports to Notion/Obsidian.

**Description:**
Fleavi is a powerful browser extension that uses AI to instantly summarize any web page. Whether you're reading research papers, blog posts, news articles, or documentation — Fleavi gives you the key insights in seconds.

KEY FEATURES:
• One-click summarization with Ctrl+Shift+S
• 4 summary formats: Bullets, Prose, Structured, Mind Map
• Adjustable length: Short, Medium, or Detailed
• Interactive AI chat — ask follow-up questions about any page
• Source citations — clickable links that highlight the original text
• Cross-language translation (20+ languages)
• Custom persona prompts: ELI5, Executive, Academic, Sales, Casual
• Read Later list with daily digest automation
• Export to Notion, Obsidian, Readwise, and Kindle
• Dark mode and keyboard shortcuts
• Free tier: 20 summaries/day with no API key required

PRIVACY:
• Your API key stays in your browser — never sent to our servers
• Free tier uses our proxy only for AI processing — no data is stored
• No tracking, no analytics, no ads

**Category:** Productivity

**Language:** English
